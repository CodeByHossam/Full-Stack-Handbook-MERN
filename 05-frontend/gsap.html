GSAP

The GreenSock Animation Platform: professional web animation with tweens, timelines and ScrollTrigger — including clean React integration.

Frontend Animation

Install & import

GSAP is a JavaScript animation library. Unlike CSS transitions and keyframes, it lets you sequence many elements on a precise timeline, drive animation from scroll, and control easing and playback programmatically — which is why it is the standard for polished marketing sites and app UI.

npm install gsap
import gsap from "gsap";

GSAP is used for web animations: landings, hero sections, scroll effects, timelines, text/SVG animation and parallax.

Tweens: to, from, fromTo

A "tween" animates one or more properties over time. The three core methods differ only in where the start and end values come from — to() animates toward a target, from() animates in from a given start state, and fromTo() sets both ends explicitly.

<div class="box"></div>
// Animate FROM the current state TO these values
gsap.to(".box", { x: 300, duration: 1 });   // 0 → 300

// Start at a value and animate to the normal position
gsap.from(".box", { x: -300, duration: 1 });

// Define both ends explicitly
gsap.fromTo(
    ".box",
    { x: -300, opacity: 0 },
    { x: 0, opacity: 1, duration: 1 }
);
Key point

to() starts from wherever the element is now. from() is ideal for entrance animations.

MethodStarts fromCommon use
to()The element's current stateMove/scale on click or hover
from()The values you passEntrance / reveal animations
fromTo()Explicit start, explicit endRepeatable, predictable sequences

Common properties

Tweens accept a mix of position, transform and appearance properties, plus control keys like duration. GSAP turns x/y into CSS transforms automatically, so these are the smooth, GPU-friendly properties you should reach for most.

gsap.to(".box", {
    x: 100,
    y: 50,
    rotation: 360,
    scale: 1.5,
    opacity: 0.5,
    duration: 2
});
GroupProperties
Positionx, y
Rotationrotation, rotationX, rotationY
Scalescale, scaleX, scaleY
Appearanceopacity, width, height, color, backgroundColor

Duration, delay & easing

duration is measured in seconds, delay waits before starting, and ease shapes the speed curve over time. The ease is what makes motion feel natural rather than robotic — always pick one instead of leaving the default linear.

gsap.to(".box", { x: 300, duration: 2 });      // seconds
gsap.to(".box", { x: 300, duration: 1, delay: 2 }); // wait 2s, then animate
gsap.to(".box", { x: 500, duration: 2, ease: "power2.out" });
EaseFeel
"none" / "linear"Constant speed
"power1.out" … "power4.out"Smooth deceleration; power2.out for UI, power3.out for entrances
"back.out"Playful overshoot
"elastic.out"Springy
"bounce.out"Bouncing finish
"circ.out"Circular easing

Repeat & yoyo

repeat and yoyo turn a one-shot tween into a loop. yoyo: true reverses direction on each repeat, which is ideal for pulsing, bouncing or ping-pong effects.

gsap.to(".box", { x: 300, duration: 1, repeat: 3 });

// Infinite spin
gsap.to(".box", { rotation: 360, duration: 2, repeat: -1 });

// Ping-pong: 0 → 300 → 0 → 300 …
gsap.to(".box", { x: 300, duration: 1, repeat: -1, yoyo: true });

repeat: -1 means repeat forever. repeat: 3 means the initial run plus three repeats.

Callbacks

Callbacks fire at lifecycle points of a tween, so you can run code exactly when an animation starts, updates or ends — the clean way to chain logic without guessing setTimeout durations.

gsap.to(".box", {
    x: 300,
    duration: 1,
    onComplete: () => {
        console.log("Animation finished");
    }
});

Useful callbacks: onStart, onUpdate, onComplete, onRepeat.

Selectors & stagger

GSAP accepts any CSS selector (or a DOM node / React ref) and animates every match. stagger then offsets their start times so they cascade in one after another instead of moving in lockstep.

gsap.to(".box", { x: 200 });   // class
gsap.to("#box", { x: 200 });   // id

// Stagger: items start one after another
gsap.from(".item", {
    y: 50,
    opacity: 0,
    duration: 1,
    stagger: 0.2
});

GSAP animates every matching element. Stagger is one of its most useful features for lists, menus and galleries.

Timelines

A timeline sequences animations so you don't have to chain callbacks and delays.

const tl = gsap.timeline();

tl.to(".box", { x: 300, duration: 1 });
tl.to(".circle", { y: 200, duration: 1 });   // runs after the box
TweenTimeline
UnitOne animationA sequence of tweens
ControlPlay / pausePlay, pause, reverse and seek as one group
Best forA single movementMulti-step sequences and hero intros

Position parameters & labels

The third argument to tl.to() is the position parameter, which controls when a tween starts on the timeline. A number places it at that absolute second, "+=0.5" / "-=0.5" offset from the previous tween's end, and "<" starts it together with the previous tween. Labels name a point in time so complex timelines can be sought and reused.

const tl = gsap.timeline();

tl.to(".box", { x: 300, duration: 1 });

// Start 0.5s BEFORE the previous animation finishes
tl.to(".circle", { y: 200, duration: 1 }, "-=0.5");

// Start at the SAME time as the previous animation
tl.to(".ring", { scale: 2, duration: 1 }, "<");

// Delay the whole timeline
const tl2 = gsap.timeline({ delay: 1 });

// Labels organize complex timelines
tl.addLabel("start");
tl.to(".box", { x: 300 });
tl.addLabel("middle");
tl.to(".circle", { y: 200 });

Controlling a timeline

Because a timeline is one object, a single call controls the whole sequence — pause(), play(), reverse() and restart() act on every tween it contains. progress(0.5) jumps to the halfway point, which is useful for tying a timeline to a slider or scroll value.

tl.pause();
tl.play();
tl.reverse();
tl.restart();
tl.progress(0.5);   // seek to 50% (0..1)

React integration

React owns the DOM, so selector-based tweens can leak across components or outlive unmount. Use a ref to scope animation to one subtree and gsap.context() to collect every tween it creates so they can all be reverted at once.

Warning

Don't blindly write gsap.to(".box", {...}) inside React components. Use refs and gsap.context() so animations are scoped and cleaned up on unmount.

import { useLayoutEffect, useRef } from "react";
import gsap from "gsap";

function Hero() {
    const container = useRef(null);

    useLayoutEffect(() => {
        const ctx = gsap.context(() => {
            gsap.from(".title", {
                y: 50,
                opacity: 0,
                duration: 1
            });
        }, container);

        return () => ctx.revert();
    }, []);

    return (
        <div ref={container}>
            <h1 className="title">Welcome</h1>
        </div>
    );
}

You can also animate a specific element through a ref:

const boxRef = useRef(null);

useLayoutEffect(() => {
    gsap.to(boxRef.current, { x: 200, duration: 1 });
}, []);

<div ref={boxRef}>Box</div>
Note

useLayoutEffect() runs before the browser paints, which is why it's a good fit for GSAP measuring and manipulating the DOM.

ScrollTrigger

ScrollTrigger (a free plugin) runs an animation based on scroll position instead of time — revealing a section as it enters the viewport, pinning a section while it animates, or linking progress directly to the scrollbar with scrub. Register it once after importing.

import { ScrollTrigger } from "gsap/ScrollTrigger";
gsap.registerPlugin(ScrollTrigger);

gsap.to(".box", {
    x: 500,
    scrollTrigger: {
        trigger: ".box",
        start: "top 80%",
        end: "top 30%"
    }
});
OptionMeaning
triggerElement whose position drives the animation
start / endPositions like "top 80%", "top top", "center center"
scrub: trueAnimation follows scroll position (parallax/storytelling)
scrub: 1Smoothly catches up to the scroll position
pin: trueKeep the section pinned while the animation progresses
toggleActionsonEnter onLeave onEnterBack onLeaveBack, e.g. "play none none reverse"
markers: trueDebug markers — remove before production
 
const tl = gsap.timeline({
    scrollTrigger: {
        trigger: ".hero",
        start: "top top",
        end: "+=1000",
        scrub: true,
        pin: true
    }
});

tl.to(".title", { y: -100, opacity: 0 });
tl.to(".image", { scale: 1.5 });

Text animation

You can animate opacity, position, scale, color, and — with the SplitText plugin — characters, words and lines. Splitting text into spans lets you stagger each unit for a typing or reveal effect.

gsap.from(".headline", {
    y: 40,
    opacity: 0,
    duration: 1,
    ease: "power3.out"
});

set, kill & utilities

gsap.set() applies values instantly with no animation, which is perfect for establishing initial states before a tween runs. kill* stops running tweens, and the utils helpers do math, clamping and randomness for you.

// Instantly set values with no animation (great for initial states)
gsap.set(".box", { x: 100, opacity: 0 });

// Stop active animations on an element
gsap.killTweensOf(".box");

// Utilities
gsap.utils.random(0, 100);
gsap.utils.clamp(0, 100, value);
gsap.utils.mapRange(0, 100, 0, 500, value);

// Random values per element
gsap.to(".box", { x: () => gsap.utils.random(-200, 200) });
gsap.from(".card", {
    y: 50,
    opacity: 0,
    duration: 0.8,
    stagger: 0.1
});

Performance

Prefer animating transform and opacity — x, y, scale, rotation, opacity. Avoid continuously animating top, left, width and height when a transform can achieve the same effect.

Instead of top: 100  →  prefer y: 100
Instead of left: 200 →  prefer x: 200

GSAP handles transforms efficiently. Don't over-animate: keep effects fast, purposeful, smooth and meaningful.

Accessibility: reduced motion

Some users prefer less animation. Respect prefers-reduced-motion by reducing or disabling non-essential animations.

const reduceMotion = window.matchMedia(
    "(prefers-reduced-motion: reduce)"
).matches;

if (!reduceMotion) {
    gsap.from(".hero-title", { y: 60, opacity: 0, duration: 1 });
}

Common GSAP workflow

Almost every GSAP animation follows the same loop: select the targets, build a timeline, set the initial state, animate, optionally connect it to scroll, then test and clean up on unmount.

SELECT
   ↓
CREATE TIMELINE
   ↓
SET INITIAL STATE
   ↓
ANIMATE
   ↓
CONNECT TO SCROLL
   ↓
TEST
   ↓
CLEAN UP

For larger projects, keep animation logic out of huge components — for example a useHeroAnimation.js hook or an animations/ folder with heroAnimation.js, cardAnimation.js and menuAnimation.js.

Full hero example

A complete React hero section: a timeline of from() tweens with position control, scoped by gsap.context() and cleaned up on unmount.

import { useLayoutEffect, useRef } from "react";
import gsap from "gsap";

function Hero() {
    const container = useRef(null);

    useLayoutEffect(() => {
        const ctx = gsap.context(() => {
            const tl = gsap.timeline();

            tl.from(".hero-title", {
                y: 60,
                opacity: 0,
                duration: 1,
                ease: "power3.out"
            });

            tl.from(".hero-text", {
                y: 30,
                opacity: 0,
                duration: 0.8
            }, "-=0.5");

            tl.from(".hero-button", {
                scale: 0.8,
                opacity: 0,
                duration: 0.5
            }, "-=0.3");
        }, container);

        return () => ctx.revert();
    }, []);

    return (
        <section ref={container}>
            <h1 className="hero-title">Welcome</h1>
            <p className="hero-text">Build something amazing.</p>
            <button className="hero-button">Get Started</button>
        </section>
    );
}

Quick recap

  • gsap.to(), from() and fromTo() are the core tweens.
  • duration, delay and ease control timing.
  • repeat, yoyo and callbacks shape loops and sequencing.
  • stagger animates collections in a cascade.
  • Timelines sequence with position parameters, labels and control methods.
  • In React: useRef + useLayoutEffect + gsap.context() + revert().
  • ScrollTrigger connects animation to scroll: start, end, scrub, pin, toggleActions.
  • Animate transforms/opacity for performance and honor prefers-reduced-motion.
