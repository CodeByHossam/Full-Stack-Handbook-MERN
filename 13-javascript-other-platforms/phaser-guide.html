Phaser 2D Game Development

A complete, practical Phaser 3 reference: project setup, the scene lifecycle, assets, sprites, animation, input, physics, collisions, UI, audio, particles, tilemaps, and two finished games.

Phaser 3Game DevJavaScript

What Phaser is

Phaser is a fast, free, open-source HTML5 game framework for 2D games that run in the browser. It handles the hard parts for you: rendering (WebGL with Canvas fallback), a game loop, sprites, animation, tilemaps, input (keyboard/mouse/touch/gamepad), audio, a physics engine (Arcade + Matter), particles, tweens, and a scene system for organizing game states.

You write plain JavaScript (or TypeScript). Phaser does not need a build step, but a bundler like Vite gives you ES modules, fast refresh, and a clean production build.

Key point

Everything in this page targets Phaser 3 (the current major version). The API is scene-based: you create objects inside scenes and Phaser calls your lifecycle methods automatically.

The game config

The config object tells Phaser how to render, the canvas size, the physics system, scaling behavior, and which scenes to start with.

import Phaser from "phaser";
import BootScene from "./scenes/BootScene.js";
import PreloaderScene from "./scenes/PreloaderScene.js";
import MenuScene from "./scenes/MenuScene.js";
import GameScene from "./scenes/GameScene.js";

const config = {
  type: Phaser.AUTO,               // WebGL if available, else Canvas
  parent: "game",                  // DOM element id to mount into
  width: 960,
  height: 540,
  backgroundColor: "#0b1020",
  pixelArt: true,                  // crisp pixels for retro art (disables AA)
  physics: {
    default: "arcade",             // "arcade" (simple, fast) or "matter" (realistic)
    arcade: {
      gravity: { y: 900 },         // world gravity (px/s^2); 0 for top-down
      debug: false                 // draw physics bodies — turn on while learning
    }
  },
  scale: {
    mode: Phaser.Scale.FIT,        // scale to fit the parent while keeping aspect
    autoCenter: Phaser.Scale.CENTER_BOTH
  },
  scene: [BootScene, PreloaderScene, MenuScene, GameScene]
};

new Phaser.Game(config);
OptionMeaning
typeAUTO, WEBGL, CANVAS, or HEADLESS (for tests).
width/heightGame canvas size in pixels (the "design resolution").
physics.defaultarcade = AABB, cheap, great for platformers/shooters. matter = full rigid bodies.
scale.modeFIT keeps aspect and letterboxes; RESIZE follows the window.
sceneArray of scene classes; the first one starts automatically.

The scene lifecycle (init, preload, create, update…)

A scene is a self-contained slice of your game: a menu, a level, a loading screen, a pause overlay. Phaser runs scenes through a fixed lifecycle and calls your methods in order. This is the single most important concept to understand.

MethodWhen it runsWhat to put here
init(data)First, before anything loadsRead data passed from another scene; reset local state (this.score = 0). No game objects yet.
preload()Once, after initQueue assets with this.load.*. Phaser loads them and shows progress. Create objects in create, not here.
create(data)Once, when all assets are readyBuild the world: add sprites, groups, animations, input, physics colliders, UI.
update(time, delta)Every frame (~60/s)Per-frame logic: read input, move entities, check win/lose. delta is ms since last frame.
render()Every frame, after updateRarely needed. For custom drawing over the scene (usually use Graphics instead).
shutdown()When the scene stops/restartsRemove timers, listeners, and references to avoid memory leaks.
destroy()When the scene is destroyedFinal cleanup.
 
class GameScene extends Phaser.Scene {
  constructor() {
    super("GameScene");            // unique key used by this.scene.start("GameScene")
  }

  init(data) {
    // Reset per-run state. data comes from this.scene.start("GameScene", {...})
    this.score = data.score || 0;
    this.lives = 3;
  }

  preload() {
    // Queue assets. Keys are how you reference them later.
    this.load.image("sky", "assets/sky.png");
    this.load.image("ground", "assets/platform.png");
    this.load.spritesheet("player", "assets/player.png", { frameWidth: 32, frameHeight: 48 });
    this.load.audio("jump", ["assets/jump.ogg", "assets/jump.mp3"]);
  }

  create() {
    // Assets are ready. Build the scene.
    this.add.image(480, 270, "sky");
    this.player = this.physics.add.sprite(100, 400, "player").setCollideWorldBounds(true);

    // Define an animation from the sprite sheet frames
    this.anims.create({
      key: "run",
      frames: this.anims.generateFrameNumbers("player", { start: 0, end: 3 }),
      frameRate: 12,
      repeat: -1
    });

    this.player.play("run");
  }

  update(time, delta) {
    // Runs every frame. time = ms since game start, delta = ms since last frame
    const cursors = this.cursors;
    if (cursors.left.isDown) this.player.setVelocityX(-200);
    else if (cursors.right.isDown) this.player.setVelocityX(200);
    else this.player.setVelocityX(0);
  }

  shutdown() {
    // Clean up when leaving the scene
    this.load.off("progress");
  }
}

export default GameScene;
Warning

Never create game objects (sprites, text, groups) in preload() — assets are not ready yet. Put creation in create(). preload() is only for this.load.* calls.

Note

delta lets you write frame-rate-independent movement: x += speed * (delta / 1000). Use it whenever you move something without physics velocity.

Managing multiple scenes

Split the game into scenes: Boot (tiny set-up), Preloader (load everything + progress bar), Menu, Game, GameOver, and optionally a UI/HUD scene that runs on top of the Game scene.

// Start / switch scenes (stops the current scene)
this.scene.start("MenuScene");

// Pass data to the next scene
this.scene.start("GameScene", { level: 2 });

// Run a scene on top WITHOUT stopping this one (great for HUD / pause overlays)
this.scene.launch("HudScene");
this.scene.pause("GameScene");     // freeze the game scene
this.scene.resume("GameScene");    // unfreeze it
this.scene.stop("HudScene");       // remove the overlay

// Sleep keeps the scene in memory (fast to wake) but stops update/render
this.scene.sleep("GameScene");
this.scene.wake("GameScene");

Preloader scene with a progress bar

class PreloaderScene extends Phaser.Scene {
  constructor() { super("PreloaderScene"); }

  preload() {
    const w = this.scale.width, h = this.scale.height;
    const bar = this.add.rectangle(w / 2, h / 2, 400, 24, 0x222222).setOrigin(0.5);
    const fill = this.add.rectangle(w / 2 - 200, h / 2, 0, 20, 0x4ade80).setOrigin(0, 0.5);

    this.load.on("progress", (p) => fill.width = 400 * p);
    this.load.on("complete", () => this.scene.start("MenuScene"));

    // Queue every asset the game needs
    this.load.image("sky", "assets/sky.png");
    this.load.spritesheet("player", "assets/player.png", { frameWidth: 32, frameHeight: 48 });
    this.load.audio("bgm", "assets/bgm.mp3");
  }
}
Key point

Loading all assets once in a Preloader scene keeps gameplay smooth and avoids mid-level pauses. Define all your animations there too, so every scene can use them by key.

Loading assets (images, sheets, atlases, audio, JSON)

// Single image
this.load.image("logo", "assets/logo.png");

// Sprite sheet — a grid of equally sized frames

// Texture atlas — frames packed with a JSON descriptor (efficient)

// Audio — provide several formats for browser coverage; Phaser picks one
this.load.audio("shoot", ["assets/shoot.ogg", "assets/shoot.mp3"]);

// JSON data, tilemaps, bitmap fonts
this.load.json("levels", "assets/levels.json");
this.load.tilemapTiledJSON("level1", "assets/level1.json");
this.load.bitmapFont("pixel", "assets/font.png", "assets/font.xml");

Where to get assets

  • Kenney.nl — huge library of free, CC0 (public-domain) sprite and audio packs. Best starting point.
  • OpenGameArt.org — community art under public-domain/CC licenses.
  • itch.io — free and paid game asset packs (check each license).
  • Tools: Aseprite or Piskel (pixel art), Tiled (tilemap levels), BFXR / jsfxr (retro sound effects), Audacity (edit audio), Leshy SpriteSheet Tool (pack atlases).
Warning

Always confirm the license of an asset before shipping. CC0/public-domain needs no credit; CC-BY requires attribution; many "free" packs forbid commercial use.

Sprites, images, text, and containers

// Image — static, no physics
this.add.image(480, 270, "sky");

// Sprite — can be animated / have physics
const hero = this.physics.add.sprite(100, 400, "player");
hero.setScale(1.5).setFlipX(true).setTint(0xff8800).setDepth(10);

// Text
this.add.text(16, 16, "Score: 0", { fontSize: "20px", color: "#ffffff" });

// Graphics — draw shapes and lines
const g = this.add.graphics();
g.fillStyle(0x4ade80, 1).fillCircle(480, 270, 40);

// Container — group objects so they move together (e.g., a player + health bar)
const container = this.add.container(100, 400, [hero]);
container.x += 10;               // moves the whole group
Note

Set depth (z-index) to control draw order: higher numbers draw on top. Backgrounds low, players mid, UI high.

Sprite animation

Animations are defined from sprite-sheet frame ranges or atlas frame names, then played on a sprite by key.

// From a sprite sheet: frames 0..3 are the walk cycle
this.anims.create({
  key: "walk",
  frames: this.anims.generateFrameNumbers("player", { start: 0, end: 3 }),
  frameRate: 10,
  repeat: -1                       // -1 = loop forever
});

// From an atlas: list frames by name
this.anims.create({
  key: "explode",
  frames: this.anims.generateFrameNames("tiles", { prefix: "boom_", start: 0, end: 5 }),
  frameRate: 15,
  repeat: 0                        // play once
});

// Play and control
sprite.play("walk");
sprite.play("explode").once("animationcomplete", () => sprite.destroy());
sprite.anims.pause();
sprite.anims.stop();
sprite.setTexture("player", 0);    // reset to a single frame
Key point

Define animations once (usually in Preloader or a shared setup) and reference them by key everywhere. Playing a not-yet-created animation silently does nothing — a common bug.

Movement, velocity, and the camera

update() {
  const speed = 220, jump = -520;
  if (this.cursors.left.isDown) {
    this.player.setVelocityX(-speed);
    this.player.setFlipX(true);
  } else if (this.cursors.right.isDown) {
    this.player.setVelocityX(speed);
    this.player.setFlipX(false);
  } else {
    this.player.setVelocityX(0);
  }

  // Jump only when standing on the ground
  if (this.cursors.up.isDown && this.player.body.blocked.down) {
    this.player.setVelocityY(jump);
    this.jumpSound.play();
  }
}
// Camera: follow the player smoothly, keep them inside the world, add effects

Physics and collisions (Arcade)

Arcade physics gives every dynamic body a velocity and gravity, and detects axis-aligned collisions. It is fast and perfect for platformers and top-down shooters.

create() {
  // Static group — platforms do not move
  this.platforms = this.physics.add.staticGroup();
  const ground = this.platforms.create(480, 520, "ground");
  ground.setScale(2).refreshBody();          // refreshBody() after resizing a static body

  // Dynamic player
  this.player = this.physics.add.sprite(100, 300, "player");
  this.player.setBounce(0.1).setCollideWorldBounds(true);

  // Colliders: solid collision (player stands on platforms)
  this.physics.add.collider(this.player, this.platforms);

  // Overlap: detect touching WITHOUT blocking (coins, triggers)
  this.coins = this.physics.add.group({ key: "coin", repeat: 9, setXY: { x: 80, y: 400, stepX: 80 } });
  this.physics.add.collider(this.coins, this.platforms);
  this.physics.add.overlap(this.player, this.coins, this.collectCoin, null, this);
}

collectCoin(player, coin) {
  coin.disableBody(true, true);   // hide + remove from physics (great for pooling)
  this.score += 10;
  this.scoreText.setText("Score: " + this.score);
}

Bodies, velocity, and checks

  • body.setVelocity(x, y), setAcceleration, setDrag, setMaxVelocity, setGravityY, setBounce.
  • body.blocked.down / touching.down — true when standing on something.
  • body.onFloor() — convenient ground test for jumps.
  • body.setSize(w, h) / setOffset(x, y) — shrink the hitbox to match the visible sprite.
  • Switch modes with this.physics.arcade.overlap(...) (non-blocking) vs collider(...) (blocking).
Key point

Use groups for anything you spawn in numbers (bullets, enemies, coins). Groups give one collider for all children and support object pooling.

Groups and object pooling

// Physics group for bullets you fire often
this.bullets = this.physics.add.group({
  classType: Phaser.Physics.Arcade.Image,
  maxSize: 30,                       // reuse instead of creating/destroying
  runChildUpdate: true
});

function fire(x, y) {
  const b = this.bullets.get(x, y, "bullet");
  if (!b) return;                    // pool full
  b.setActive(true).setVisible(true);
  b.body.reset(x, y);
  b.setVelocityY(-500);
}

// Recycle on hit instead of destroying
this.physics.add.overlap(this.bullets, this.enemies, (bullet, enemy) => {
  bullet.disableBody(true, true);    // returns it to the pool
  enemy.destroy();
});

Tilemaps (Tiled)

// Preload: this.load.tilemapTiledJSON("level1", "assets/level1.json");

create() {

Game 1 — Platformer (full walkthrough)

Goal: run, jump across platforms, collect coins, reach the flag. Uses gravity, static platforms, overlap for coins, and a HUD.

class GameScene extends Phaser.Scene {
  constructor() { super("GameScene"); }

  preload() {
    this.load.image("sky", "assets/sky.png");
    this.load.image("ground", "assets/platform.png");
    this.load.image("coin", "assets/coin.png");
    this.load.spritesheet("player", "assets/player.png", { frameWidth: 32, frameHeight: 48 });
  }

  create() {
    this.add.image(480, 270, "sky");

    // Animations
    this.anims.create({ key: "run", frames: this.anims.generateFrameNumbers("player", { start: 0, end: 3 }), frameRate: 12, repeat: -1 });
    this.anims.create({ key: "idle", frames: [{ key: "player", frame: 0 }], frameRate: 1 });

    // World + camera
    this.physics.world.setBounds(0, 0, 3200, 600);
    this.cameras.main.setBounds(0, 0, 3200, 600);

    // Platforms
    this.platforms = this.physics.add.staticGroup();
    this.platforms.create(400, 568, "ground").setScale(2).refreshBody();
    this.platforms.create(1200, 450, "ground").refreshBody();
    this.platforms.create(1800, 350, "ground").refreshBody();
    this.platforms.create(2600, 500, "ground").setScale(2).refreshBody();

    // Player
    this.player = this.physics.add.sprite(100, 400, "player").setCollideWorldBounds(true);
    this.physics.add.collider(this.player, this.platforms);
    this.player.anims.play("idle");

    // Coins
    this.coins = this.physics.add.group({ key: "coin", repeat: 11, setXY: { x: 60, y: 0, stepX: 90 } });
    this.coins.children.iterate(c => c.setBounceY(Phaser.Math.FloatBetween(0.2, 0.5)));
    this.physics.add.collider(this.coins, this.platforms);
    this.physics.add.overlap(this.player, this.coins, this.collect, null, this);

    // Input + HUD
    this.cursors = this.input.keyboard.createCursorKeys();
    this.score = 0;
    this.scoreText = this.add.text(16, 16, "Score: 0", { fontSize: "18px", color: "#fff" }).setScrollFactor(0);

    this.cameras.main.startFollow(this.player, true, 0.1, 0.1);
  }

  collect(player, coin) {
    coin.disableBody(true, true);
    this.score += 10;
    this.scoreText.setText("Score: " + this.score);
    if (this.coins.countActive(true) === 0) {
      this.add.text(480, 270, "YOU WIN!", { fontSize: "48px", color: "#4ade80" })
        .setOrigin(0.5).setScrollFactor(0);
    }
  }

  update() {
    const speed = 220;
    if (this.cursors.left.isDown) {
      this.player.setVelocityX(-speed).setFlipX(true).anims.play("run", true);
    } else if (this.cursors.right.isDown) {
      this.player.setVelocityX(speed).setFlipX(false).anims.play("run", true);
    } else {
      this.player.setVelocityX(0).anims.play("idle", true);
    }
    if (this.cursors.up.isDown && this.player.body.blocked.down) {
      this.player.setVelocityY(-520);
    }
  }
}

Game 2 — Top-Down Shooter (full walkthrough)

Goal: move in 8 directions, shoot upward at falling enemies, survive and score. Uses no gravity, a bullet pool, timed enemy spawns, and collisions for damage.

class ShooterScene extends Phaser.Scene {
  constructor() { super("ShooterScene"); }

  preload() {
    this.load.image("bg", "assets/space.png");
    this.load.image("ship", "assets/ship.png");
    this.load.image("bullet", "assets/bullet.png");
    this.load.image("enemy", "assets/enemy.png");
    this.load.image("spark", "assets/spark.png");
  }

  create() {
    this.add.image(480, 270, "bg");
    this.score = 0;
    this.health = 100;

    // Player
    this.player = this.physics.add.image(480, 480, "ship").setCollideWorldBounds(true);
    this.player.body.setSize(24, 24);

    // Bullet pool
    this.bullets = this.physics.add.group({ classType: Phaser.Physics.Arcade.Image, maxSize: 40, runChildUpdate: true });
    this.physics.add.overlap(this.bullets, this.enemiesGroup(), this.hitEnemy, null, this);

    // Enemy group + spawn timer
    this.enemies = this.physics.add.group();
    this.spawn = this.time.addEvent({ delay: 800, loop: true, callback: this.spawnEnemy, callbackScope: this });

    // Damage on contact
    this.physics.add.overlap(this.player, this.enemies, this.takeDamage, null, this);

    // Particles
    this.sparks = this.add.particles(0, 0, "spark", { speed: 160, lifespan: 400, scale: { start: 1, end: 0 }, emitting: false });

    // Input
    this.cursors = this.input.keyboard.createCursorKeys();
    this.keys = this.input.keyboard.addKeys("W,A,S,D,SPACE");
    this.spaceCooldown = 0;

    this.scoreText = this.add.text(16, 16, "Score: 0", { fontSize: "18px", color: "#fff" }).setScrollFactor(0);
  }

  enemiesGroup() { return this.enemies; }

  spawnEnemy() {
    const x = Phaser.Math.Between(40, 920);
    const e = this.enemies.create(x, -20, "enemy");
    e.setVelocityY(Phaser.Math.Between(80, 160));
  }

  hitEnemy(bullet, enemy) {
    bullet.disableBody(true, true);
    this.sparks.explode(12, enemy.x, enemy.y);
    enemy.destroy();
    this.score += 5;
    this.scoreText.setText("Score: " + this.score);
  }

  takeDamage(player, enemy) {
    enemy.destroy();
    this.sparks.explode(12, player.x, player.y);
    this.health -= 10;
    this.cameras.main.shake(150, 0.01);
    if (this.health <= 0) return this.gameOver();
  }

  gameOver() {
    this.spawn.remove();
    this.physics.pause();
    this.add.text(480, 270, "GAME OVER", { fontSize: "48px", color: "#ff5555" }).setOrigin(0.5).setScrollFactor(0);
    this.input.keyboard.once("keydown-SPACE", () => this.scene.restart());
  }

  update(time, delta) {
    const speed = 260;
    let vx = 0, vy = 0;
    if (this.cursors.left.isDown || this.keys.A.isDown) vx = -speed;
    if (this.cursors.right.isDown || this.keys.D.isDown) vx = speed;
    if (this.cursors.up.isDown || this.keys.W.isDown) vy = -speed;
    if (this.cursors.down.isDown || this.keys.S.isDown) vy = speed;
    this.player.setVelocity(vx, vy);

    this.spaceCooldown -= delta;
    if (this.keys.SPACE.isDown && this.spaceCooldown <= 0) {
      const b = this.bullets.get(this.player.x, this.player.y - 24, "bullet");
      if (b) {
        b.setActive(true).setVisible(true);
        b.body.reset(this.player.x, this.player.y - 24);
        b.setVelocityY(-600);
      }
      this.spaceCooldown = 180;      // ms between shots
    }
  }
}
Key point

These two games cover ~90% of the techniques in real 2D games: scenes, asset loading, animation, input, gravity vs top-down movement, colliders vs overlaps, groups/pools, camera, particles, tweens, HUD, and game states. Build them, then remix them.

Best practices & optimization

  • One Preloader scene for all assets; define animations there.
  • Groups + pooling for anything spawned in numbers; never create/destroy bullets every frame.
  • Use texture atlases to reduce draw calls and HTTP requests.
  • Keep update() light. Do not allocate objects every frame; reuse.
  • Scale assets appropriately; large images cost memory and GPU bandwidth.
  • Clean up in shutdown(): remove timers and listeners to avoid leaks when scenes restart.
  • Use setDepth and setScrollFactor(0) for HUD.
  • Build for production with vite build and serve the static output from any host or CDN.
  • Test on mobile — use pointer input and the scale config for touch devices.
