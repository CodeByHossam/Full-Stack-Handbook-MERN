Terminal & Command Line

Operating system, terminal, shell, PowerShell, CMD, Bash, Node.js, and npm — what each term actually means and how they fit together.

Fundamentals Command line Tooling

Operating system (OS)

The OS is the main software that manages the computer: it controls the CPU, memory, disk, and network, runs programs as processes, and provides the filesystem. Examples: Windows, Linux, macOS.

You rarely talk to the OS directly. You use a terminal, which runs a shell, which asks the OS to do the work.

Terminal

A terminal is a window where you type commands. Terminal is not an operating system and not a programming language.

Examples: Windows Terminal, VS Code Terminal.

Shell

A shell is a program that lets you communicate with the OS using commands. Instead of clicking buttons, you type commands.

You → Shell → Operating System

Common shells: PowerShell, CMD, Bash.

PowerShell

PowerShell is a shell and a scripting language created by Microsoft, commonly used on Windows.

cd myApp        # change directory into myApp
ls              # list files here (alias for Get-ChildItem)
mkdir test      # create a folder named test

CMD

CMD (Command Prompt) is another Windows shell. CMD is not MS-DOS — MS-DOS is an old operating system, while CMD is a Windows command shell.

cd myApp        # change directory into myApp
dir             # list files (CMD's version of ls)
mkdir test      # create a folder named test

Bash

Bash is another shell and scripting language, common on Linux, macOS, and servers.

ls              # list files here
cd myApp        # change directory into myApp
mkdir test      # create a folder named test

Terminal vs shell

The terminal is the window; the shell is the program that interprets your commands.

Windows Terminal vs VS Code Terminal

Both are terminal interfaces:

  • Windows Terminal — a separate Windows application.
  • VS Code Terminal — a terminal built inside VS Code.

Both can run PowerShell, CMD, Bash, and other shells.

Node.js

Node.js is not a shell. It is a runtime that executes JavaScript outside the browser.

node -v   # print the installed Node.js version (use it to check your setup)

Here PowerShell launches the Node.js program:

PowerShell
    ↓
Node.js
    ↓
JavaScript

npm

npm is the package manager for Node.js. It is a program you run from the shell.

npm -v          # print the npm version
npm install     # read package.json and download the project's dependencies
npm run dev     # run the "dev" script defined in the package.json "scripts" block
Watch out

npm install updates package-lock.json and may change versions; in CI or production use npm ci to install exactly the locked versions.

How they work together

Different technologies work together. Consider the command node app.js:

node        → Node.js program
app.js      → JavaScript file
PowerShell  → launches Node.js
Node.js     → executes the JavaScript
Key point

node app.js is not JavaScript code — it is a shell command used to launch Node.js, which then runs the file.

Essential Linux file commands

On Linux servers (where you deploy MERN apps) these are the everyday file and folder commands. They are the same verbs you use in Bash on macOS.

CommandWhat it doesExample

Watch out

rm -rf deletes recursively and permanently with no recycle bin, and rmdir only removes empty directories. Double-check the path before you run either.

Linux process & package commands

Once you are on a server you also manage processes, services, and packages. sudo runs a single command with administrator (root) rights.

top                          # live CPU/memory usage of running processes
kill 1234                    # send a signal to terminate process 1234
sudo apt update              # refresh the package index (needs root)
sudo apt install nginx       # install a package (needs root)
sudo systemctl start nginx   # start a service via systemd
sudo systemctl status nginx  # check whether the service is running
exit                         # close the shell session

Mount points live under /mnt — external or additional filesystems are attached there:

ls /mnt/     # list mounted filesystems
cd /mnt/     # enter the mount directory
Note

Package and service managers differ by distro: Debian/Ubuntu use apt and systemctl, which is also what you run when deploying to a VPS.

Quick recap

  • OS = manages the computer (Windows, Linux, macOS).
  • Terminal = where you type commands (Windows Terminal, VS Code Terminal).
  • Shell = interprets your commands (PowerShell, CMD, Bash).
  • CMD is a Windows shell, not MS-DOS.
  • Node.js is a runtime that runs JavaScript, not a shell.
  • npm is the package manager for Node.js, run from the shell.
  • node app.js is a command that launches Node.js on a file.
  • Linux file commands: ls, cd, pwd, mkdir, rmdir, rm, cp, mv, cat, grep, chmod.
  • Server commands: top, kill, sudo, apt, systemctl; mounts live under /mnt.
