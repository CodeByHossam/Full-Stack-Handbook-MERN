JavaScript Basics

Core JavaScript concepts, arrays, objects, modern syntax, functions, DOM, events, async, and JSON.

JavaScript Core Language

Part 1: Core language

Variables

Variables store values in named slots. Default to const (cannot be reassigned), use let when the value must change, and avoid var (function-scoped, hoisted, legacy).

let name = "Alice";       // can be changed
const age = 30;           // cannot be reassigned
var oldWay = "avoid";     // old style

let score = 10;
score = 20;               // reassignment is allowed with let

Data types

JavaScript is dynamically typed: a variable can hold any value and the type is decided at runtime. The primitives are string, number, boolean, null, undefined (plus symbol/bigint); arrays and objects are reference types.

let text = "Hello";        // String
let number = 25;           // Number
let isActive = true;       // Boolean
let nothing = null;        // Null (intentional "no value")
let notDefined;            // Undefined (declared but not assigned)

let fruits = ["apple", "banana"];     // Array
let user = { name: "Alice", age: 30 }; // Object
console.log(typeof fruits);            // "object" — arrays are objects

Strings

Strings are immutable sequences of characters with many built-in helpers. Use template literals (backticks) to combine text and values cleanly.

let firstName = "Alice";

firstName.length;                 // length
firstName.toUpperCase();          // ALICE
firstName.toLowerCase();          // alice
firstName.includes("lic");        // true
firstName.startsWith("A");        // true
firstName.endsWith("e");          // true

// Template literal
let message = `Hello ${firstName}`;
console.log(message);

Numbers & Math

All numbers are 64-bit floats (there is no separate integer type). Math provides rounding, min/max and random helpers; % gives the remainder and ** is power.

let x = 10;

x + 5;       // addition
x - 5;       // subtraction
x * 5;       // multiplication
x / 5;       // division
x % 3;       // remainder
x ** 2;      // power

Math.round(4.6);    // 5
Math.floor(4.9);    // 4
Math.ceil(4.1);     // 5
Math.max(10, 20);   // 20
Math.min(10, 20);   // 10
Math.random();      // random number 0-1

Comparison operators

Comparisons return booleans. Prefer ===/!== (strict: compares value and type) over ==/!= (loose: coerces types and produces surprises like "" == 0).

5 === 5;       // true
5 !== 3;       // true
5 > 3;         // true
5 < 3;         // false
5 >= 5;        // true
5 <= 5;        // true

// Prefer === over ==
5 === "5";     // false
5 == "5";      // true

Logical operators

Logical operators combine booleans: && (AND), || (OR), ! (NOT). They short-circuit, so the right side is only evaluated when needed.

true && true;     // AND
true || false;    // OR
!true;            // NOT

if (age >= 18 && isActive) {
    console.log("Allowed");
}

If / Else & Ternary

if/else runs a block based on a condition; the ternary (? :) is the expression form for choosing a value inline. See Part 4 for more on the ternary.

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}

// Ternary operator
let result = age >= 18 ? "Adult" : "Minor";

Switch

switch compares one value against several cases. Each case needs a break — without it, execution "falls through" to the next case (a common bug).

let day = "Monday";

switch (day) {
    case "Monday":
        console.log("Start");
        break; // stop here; otherwise it falls through to "Friday"
    case "Friday":
        console.log("Weekend");
        break;
    default:
        console.log("Normal day");
}

Loops

Loops repeat work. Use for when you need the index, for...of to iterate values, and for...in to iterate object keys.

// for loop
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// while loop
let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}

// for...of → values
for (const fruit of fruits) {
    console.log(fruit);
}

// for...in → object keys
for (const key in user) {
    console.log(key);
}

Part 2: Arrays

Array basics

Arrays are ordered, zero-indexed lists. Reading an index and length is O(1); assigning to an index mutates the array in place.

const fruits = ["apple", "banana", "cherry"];

fruits[0];             // apple (indexing starts at 0)
fruits[1];             // banana
fruits.length;         // 3

fruits[0] = "orange";  // change item — mutates the original array

Array methods

Arrays ship with powerful built-in methods. The key distinction is mutation: push/splice/sort/reverse change the original array, while map/filter/slice return new ones (preferred in React).

Short examples

These examples show the methods above in action. Note which calls mutate (sort, splice) and which return new arrays (map, filter, slice, concat).

// forEach
fruits.forEach((fruit) => {
    console.log(fruit);
});

// map
const numbers = [1, 2, 3, 4];
const doubled = numbers.map((num) => num * 2); // [2,4,6,8]

// filter
const evenNumbers = numbers.filter((num) => num % 2 === 0); // [2,4]

// find & findIndex
const users = [{ name: "Alice", age: 20 }, { name: "Bob", age: 30 }];
const person = users.find((u) => u.age === 30);
const personIndex = users.findIndex((u) => u.age === 30);

// some & every
const hasAdult = users.some((u) => u.age >= 18);
const allAdults = users.every((u) => u.age >= 18);

// reduce
const total = numbers.reduce((sum, num) => sum + num, 0); // 10

// sort
const nums3 = [10, 2, 5, 1];
nums3.sort((a,b) => a-b); // ascending
nums3.sort((a,b) => b-a); // descending

// slice vs splice
const items = ["A","B","C","D"];
const part = items.slice(1,3); // ["B","C"] - no mutation
const colors = ["red","blue","green"];
colors.splice(1,1); // removes "blue" - mutates
colors.splice(1,0,"yellow"); // insert

// concat & join
const combined = [1,2].concat([3,4]); // [1,2,3,4]
const names = ["Alice","Bob","Charlie"];
names.join(", "); // "Alice, Bob, Charlie"

Part 3: Objects, destructuring, spread/rest

Objects basics

Objects store key-value pairs and are the workhorse for records and config. Access known keys with dot notation and dynamic keys with bracket notation.

const person = {
    name: "Alice",
    age: 30,
    job: "Engineer"
};

// Access
person.name;
person["name"];

// Modify/add/delete
person.age = 31;
person.country = "UAE";
delete person.job;

// Object methods
Object.keys(person);      // keys
Object.values(person);    // values
Object.entries(person);   // [key,value] pairs

Destructuring

Destructuring pulls values out of arrays/objects into named variables in one line. Object destructuring matches by key (rename with :); array destructuring matches by position.

// Object
const student = { name: "Alice", age: 25 };
const { name: studentName, age: studentAge } = student; // rename while destructuring

// Array — position-based, skipping is possible
const colors = ["red", "green", "blue"];
const [first, second, third] = colors;
const [, , last] = colors; // "blue"

Spread operator (...)

Spread (...) expands an iterable or object into individual elements. Its main MERN use is immutable copies and updates — building a new array/object instead of mutating the original (required by React state).

// Copy array
const original = [1,2,3];
const copy = [...original];

// Combine arrays
const arr1 = [1,2], arr2 = [3,4];
const combined = [...arr1, ...arr2];

// Copy object
const userCopy = { ...student };

// Update object
const updatedUser = { ...student, age: 26 };

Rest operator (...)

Rest (...) collects multiple arguments (or remaining items) into a single array. Same syntax as spread, opposite job: gather instead of expand.

function addAll(...numbers) {
    return numbers.reduce((sum, num) => sum + num, 0);
}
addAll(1,2,3,4); // 10

Part 4: Modern syntax

Template literals

Template literals use backticks and ${} interpolation to build strings from variables and expressions. They replace error-prone + concatenation and allow multi-line text directly.

const name = "Alice";
const msg = `Hello ${name}, welcome!`;

// Any expression works inside ${ }, and newlines are preserved
const total = 3;
const report = `Items: ${total}
Cost: $${(total * 2).toFixed(2)}`;

Ternary

The ternary operator is a compact if/else that returns a value. Use it to choose between two values inline (for example a label or an element); because it is an expression, you can assign or return its result.

const age = 20;
const status = age >= 18 ? "Adult" : "Minor"; // "Adult"
// nested — use sparingly, prefer readable code
const grade = score >= 90 ? "A" : score >= 80 ? "B" : score >= 70 ? "C" : "F";

Logical AND (&&)

Returns the first falsy operand, or the last operand if all are truthy. The common pattern is short-circuit execution: run the right side only when the left is truthy (guards, and conditional rendering in React).

isActive && console.log("Active"); // runs console.log only if isActive is truthy

// React render guard
isLoggedIn && showDashboard();

Optional chaining (?.)

Safely reads a nested property and short-circuits to undefined instead of throwing when an intermediate value is null/undefined. Use it for API data that may be missing fields.

const user = { profile: { name: "Alice" } };
console.log(user.profile?.name);      // "Alice"
console.log(user.address?.city);      // undefined (no error)
console.log(user.greet?.());          // also guards function calls

Nullish coalescing (??)

Returns the right-hand value only when the left is null or undefined. Unlike ||, it treats 0, "", and false as valid values, so it is the safer "default value" operator.

let username = null;
let displayName = username ?? "Guest"; // "Guest"

const count = 0;
console.log(count || 10); // 10  ← wrong if 0 is a valid value
console.log(count ?? 10); // 0   ← correct: 0 is not nullish
Watch out

?? cannot be mixed with || or && without parentheses (a ?? b || c is a SyntaxError; write (a ?? b) || c).

OperatorReturns fallback when...Common use

Truthy / Falsy

Every value is coerced to a boolean in conditions. Falsy values: false, 0, "", null, undefined, NaN. Everything else is truthy.

if (username) {
    console.log("Has username"); // runs only when username is truthy
}

// Gotcha: empty array/object are truthy, and "0" is truthy
Boolean([]); // true
Boolean({}); // true
Boolean("0"); // true
Boolean("");  // false

Part 5: Functions & Callbacks (deep-dive)

What is a function?

A function is a reusable block of code that performs a task.

function greet() {
    console.log("Hello");
}
greet();

Function declaration vs expression

Declarations are hoisted, so they can be called before they appear in the file. Expressions assigned to a variable are not hoisted, so they must be defined before use.

// Function declaration (hoisted)
function greet() {
    console.log("Hello");
}
greet();

// Function expression
const greetExpr = function() {
    console.log("Hello");
};
greetExpr();

Arrow functions

Arrow functions are a shorter syntax that do not bind their own this — they inherit it from the enclosing scope, which is why they are preferred for callbacks and inside React components.

const greet = () => console.log("Hello");
const greetName = (name) => `Hello ${name}`;
const add = (a,b) => a + b;

Parameters vs Arguments

Parameter is placeholder; argument is actual value.

function greet(name) { // parameter
    console.log(name);
}
greet("Alice"); // argument

Return vs console.log

return sends a value back to the caller so it can be used; console.log only prints. A function with no return (or a bare return;) yields undefined.

function getValue() {
    return 10; // returns value
}
const val = getValue(); // val = 10

function logValue() {
    console.log(10); // prints only
}

Functions are values

Functions are first-class: you can store them in variables, attach them to objects, and pass them around like any other value.

const greet = function() { console.log("Hi"); };
const user = {
    name: "Alice",
    greet: function() { console.log("Hello"); }
};
user.greet();

Passing functions & Callbacks

A callback is a function passed to another function to be called by it.

function parent(callback) {
    console.log("Start");
    callback();
    console.log("End");
}
function child() {
    console.log("Child runs");
}
parent(child); // pass function (not child())
Note

Pass the function reference: onClick={handleClick}. Do NOT call it: onClick={handleClick()} (that would execute immediately).

// Correct (React-style example)
function handleClick() {
    console.log("Clicked");
}
// <button onClick={handleClick}>Click</button>

// Incorrect
// <button onClick={handleClick()}>Click</button>

Callback can receive/return values

Callbacks can take arguments and return values, so the parent function can pass data in and use the result that comes back.

function parent(callback) {
    const result = callback();
    console.log(result); // 10
}
parent(() => 10);

Higher-order functions

Functions that receive or return other functions.

function execute(fn) { fn(); }
execute(() => console.log("Hi"));

// Built-in example
[1,2,3].map(n => n*2);

Functions returning functions

Returning a function creates a closure: the returned function keeps access to the variables of the scope it was created in, even after that scope has finished.

function createGreeting() {
    return function() {
        console.log("Hello");
    };
}
const greet = createGreeting();
greet();

Scope

Scope decides where a variable is visible. const/let are block-scoped, and anything declared inside a function is not accessible from outside it.

function test() {
    const name = "Alice";
    console.log(name); // ok
}
test();
// console.log(name); // error (not accessible)
Key point

greet refers to function; greet() executes it.

Part 6: DOM & Events

The DOM is the live, in-memory tree of the page. JavaScript selects elements, reads or changes their content, and attaches event listeners to react to user input.

// Select elements
const button = document.getElementById("myButton");
const title = document.querySelector("h1");
const item = document.querySelector(".item");

// Change content
const output = document.getElementById("output");
output.textContent = "Hello";                 // safe: treats input as plain text
output.innerHTML = "<strong>Hello</strong>"; // parses HTML — risk of XSS with user input

// Events
button.addEventListener("click", () => {
    console.log("Clicked!");
});

// Input
const input = document.getElementById("name");
console.log(input.value);

// Classes
const box = document.querySelector(".box");
box.classList.add("active");
box.classList.remove("active");
box.classList.toggle("active");
box.classList.contains("active");
Watch out

Never insert untrusted input with innerHTML — it can execute scripts (XSS). Use textContent for plain text.

Part 7: Async (callbacks, promises, async/await, try/catch)

Callbacks (async timing)

A callback scheduled with setTimeout runs later, not now. The delay is a minimum: the callback runs only after the current synchronous code and all microtasks finish.

setTimeout(() => {
    console.log("Done");
}, 2000);

Promises

A Promise represents a value that will exist later. .then handles success, .catch handles failure, and chaining avoids deeply nested callbacks. fetch returns a Promise.

fetch("https://example.com/api")
    .then(res => res.json())
    .then(data => console.log(data))
    .catch(err => console.error(err));

Async/Await

async/await is syntax sugar over Promises. await pauses the current async function until the Promise settles, so async code reads like synchronous code — but it does not block the rest of the program.

async function getData() {
    const response = await fetch("https://example.com/api");
    const data = await response.json();
    console.log(data);
}

Try/Catch

Wrap await calls in try/catch to handle rejections and network errors. An uncaught rejection inside an async function otherwise propagates as a rejected Promise.

async function getDataSafe() {
    try {
        const res = await fetch("https://example.com/api");
        const data = await res.json();
        console.log(data);
    } catch (error) {
        console.log(error);
    }
}

Part 8: JSON

JSON (JavaScript Object Notation) is the text format APIs send and receive. JSON.stringify turns a JS value into a JSON string (for requests/storage), and JSON.parse turns that string back into objects.

const userData = { name: "Alice", age: 30 };

// Object → JSON
const json = JSON.stringify(userData);

// JSON → Object
const obj = JSON.parse(json);

// Gotcha: functions and undefined are dropped by stringify
JSON.stringify({ a: 1, b: undefined, c: () => {} }); // "{\"a\":1}"

Misc concepts

Array cycling with %

The modulo operator % wraps an index back to 0 once it reaches the array length — handy for carousels and rotating through options.

let index = 0;
const arr = ["a","b","c"];
index = (index + 1) % arr.length; // 0 → 1 → 2 → 0 ...

Array patterns

A quick reference of the array operations you will reach for constantly in MERN code.

for (const item of myArray) { /* ... */ }
const upper = myArray.map(x => x.toUpperCase());
const filtered = myArray.filter(x => x.length > 5);
const found = myArray.find(x => x === "apple");
const exists = myArray.includes("apple");

Quick recap

  • Prefer const/let; use === over ==.
  • Arrays: map/filter/find/reduce for transformations/selection; watch mutation vs non-mutation.
  • Objects: destructuring, spread/rest for immutable updates.
  • Modern JS: ?., ??, template literals, truthy/falsy.
  • Callbacks: pass function reference (fn), not call (fn()).
  • Async: Promise + async/await with try/catch.
  • JSON: stringify / parse.
