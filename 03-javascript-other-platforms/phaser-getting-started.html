Phaser: Getting Started

What is Phaser, installation, project setup (Vite), first config, game loop basics.

What is Phaser?

Phaser is a fast, open-source 2D HTML5 game framework. It handles rendering (Canvas/WebGL), physics, sprites, input, audio, scenes, tweens.

Installation

mkdir phaser-game && cd phaser-game
npm init -y
npm i phaser
npm i -D vite
{"scripts":{"dev":"vite","build":"vite build","preview":"vite preview"}}

phaser-game/

Phaser Config Explained

import Phaser from 'phaser';
const config = {
  type: Phaser.AUTO,        // Canvas or WebGL
  width: 800,
  height: 600,
  backgroundColor: '#1e1e1e',
  physics: { default: 'arcade', arcade: { gravity: { y: 0 }, debug: false } },
  scale: { mode: Phaser.Scale.FIT, autoCenter: Phaser.Scale.CENTER_BOTH },
  scene: []
};
new Phaser.Game(config);

First Scene

class BootScene extends Phaser.Scene {
  constructor(){ super('Boot'); }
  preload(){ this.load.image('logo','assets/logo.png'); }
  create(){ this.add.image(400,300,'logo'); }
}
const config={type:Phaser.AUTO,width:800,height:600,scene:[BootScene]};
new Phaser.Game(config);
