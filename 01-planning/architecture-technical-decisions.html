Software Architecture & Technical Decisions

Choose structure based on requirements, not trends. Favor modular monolith before microservices.

Architectural styles

StyleWhen to useNotes
Modular monolithMost MERN appsClear boundaries, easy to test, low ops overhead
MonolithSmall/simpleFast to start
MicroservicesIndependent teams, high scale domainsComplex, only when justified
Layered (3-tier)Clear separationRoutes → controllers → services → models → DB

  • Trust boundaries: frontend untrusted, server enforces
