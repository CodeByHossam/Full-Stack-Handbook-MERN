Requirements Engineering

Gather, analyze, document, validate, and trace requirements before implementation.

Functional requirements

  • User authN/Z, roles/permissions
  • Core business workflows
  • CRUD, notifications, reports, payments, integrations, admin

Non-functional requirements

  • Performance, scalability, availability, reliability
  • Security, privacy, accessibility, usability
  • Maintainability, extensibility, observability
  • Backups/DR, compatibility, compliance, retention

Tip

Small projects: brief + user stories + acceptance criteria. Scale up only when needed.

User story format

As a [user role]
I want [capability]
So that [benefit]

Acceptance Criteria:
- Given [context], When [action], Then [outcome]
- Edge cases covered
